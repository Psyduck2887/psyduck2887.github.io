## 项目概览

Duck Guard 是一个面向 AI Coding 工作区的本地保护工具，用来自动保存文件历史，并恢复被 Agent 误删或改坏的文件。

它以守护进程持续观察工作区，通过 `start`、`undo` 和 `stop` 提供简单操作，历史数据只保存在本机。

## 当前状态

- 已发布 `v1.0.0`。
- 已上架 PyPI。
- 配套 Agent Skill，可以由 Code Agent 直接调用。
