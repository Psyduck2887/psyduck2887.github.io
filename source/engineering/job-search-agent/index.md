## 项目概览

这是一套持续迭代的 AI 求职工作流，目前包含职位搜索与分析、简历模板生成、定向简历生成和招聘沟通辅助四个部分。

前三条工作流已经完成实际交付；招聘沟通辅助仍处于受控开发阶段，所有对外消息必须经过人工确认。

## 当前能力

- 把职位信息整理成可复核的结构化数据。
- 从参考图生成可复用的 Design 和 Code 简历模板。
- 根据个人事实与目标职位生成多格式定向简历。
- 对生成内容执行来源校验、零编造门禁和视觉检查。
